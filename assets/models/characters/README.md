# Modelos GLB opcionais

A versão atual usa personagens procedurais originais. Nenhum GLB externo foi incluído.

Para uma substituição futura, coloque aqui os modelos e seus créditos/licenças e configure o dicionário `external_models` da cena compartilhada `scenes/player/character_visual.tscn`. As chaves são `lucas`, `marina`, `rafael`, `bia`; os valores são cenas importadas pelo Godot.

O contrato de escala, orientação, animações, fallback e validação está em `docs/MODELOS_GLB.md`. O corpo do jogador e a câmera continuam em `scenes/player/guardian.tscn`; não devem ser substituídos pelo GLB.
